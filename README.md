                                                # Django Homework

Проект на **Django** с базовым функционалом домашней страницы и формы обратной связи.

## Структура

* **`catalog/`** - основное приложение .
* **`config/`** - настройки проекта Django.
* **`static/`** - стили (CSS), скрипты (JS) и изображения.
* **`manage.py`** - управление проектом.

## Запуск

1. **Установите зависимости:**
   ```
   pip install -r requirements.txt
   ```

2. **Запустите сервер:**
   ```
   python manage.py runserver
   ```
