                                                # Django Homework

Проект на **Django** с базовым функционалом домашней страницы и формы обратной связи.

## Структура

* **`catalog/`** - основное приложение (модели `Category` и `Product`, админ-панель, представления и шаблоны).
* **`catalog/management/commands/`** - кастомные команды управления (`add_products.py`).
* **`config/`** - настройки проекта Django.
* **`static/`** - стили (CSS), скрипты (JS) и изображения.
* **`categories.json` / `products.json`** - фикстуры с тестовыми данными для категорий и продуктов.
* **`.env.sample`** - шаблон файла с переменными окружения.
* **`manage.py`** - управление проектом..

## Запуск

1. **Установите зависимости:**
   ```
   pip install -r requirements.txt
   ```

2. **Настройте переменные окружения:**
   Скопируйте файл `.env.sample` в `.env` и заполните параметры подключения к вашей базе данных PostgreSQL.

3. **Примените миграции:**
   ```
   python manage.py migrate
   ```

4. **Наполните базу тестовыми данными (на выбор):**
   * Через кастомную команду:
     ```
     python manage.py add_products
     ```

5. **Создайте суперпользователя для доступа в админку:**
   ```
   python manage.py createsuperuser
   ```

6. **Запустите сервер:**
   ```
   python manage.py runserver
   ```
   После запуска админ-панель будет доступна по адресу `http://127.0.0`.
